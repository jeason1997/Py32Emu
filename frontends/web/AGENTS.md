# Web 调试台规则

- Node 服务只负责安全解析请求、限制固件路径和转发 C 后端协议；不实现 MCU 行为。
- 后端协议新增字段或命令时，同步修改 C 后端、Node 路由、浏览器 UI 和集成测试。
- 必须支持加载、复位、精确单步、按步运行、多断点、寄存器、内存和符号反汇编；外设面板
  显示真实 C 模型状态。
- 固件路径必须限制在仓库范围内；数值、数组长度和内存读取数量必须有边界检查。
- 修改 UI 后实际启动 Web，检查页面布局、交互、错误提示和数据更新，不能只做语法检查。
- 自动测试启动的 Node/后端进程必须在结束时停止并释放端口；不得终止用户自行启动的进程。
- 页面不得因为某个外设不存在而报错；按 `peripherals` 能力位隐藏或禁用相应控件。
