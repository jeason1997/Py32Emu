# C11 核心、芯片与外设模型规则

本规则适用于 `src/` 以及对应的 `include/py32emu/` 公共接口。

## CPU、总线与异常

- CPU 只实现 ARMv6-M/Cortex-M0+ 语义，不包含 PY32 型号地址或外设特例。
- 指令实现必须同时考虑结果、APSR 标志、PC/SP 对齐、异常路径和周期；新增指令要有边界测试。
- 非法指令、未对齐和总线故障按 Cortex-M0+ 语义进入 HardFault，不用进程崩溃代替固件异常。
- NVIC、SysTick、SCB、MSP/PSP 和 `EXC_RETURN` 的修改要验证线程/Handler、嵌套与屏蔽状态。
- 总线设备拒绝访问时必须记录一致的故障地址；保留位读写行为以手册为准。

## 芯片描述与装配

- 容量、页大小、复位时钟、外部 IRQ 数和外设能力位只放在芯片描述中。
- SoC 装配层集中处理地址映射和 IRQ 连线；公共外设模型不得依赖 `Py32Soc`。
- 增加 PY32F003 前先核对其 CMSIS/手册差异，不通过复制 PY32F002A 描述伪造支持。
- 外设复位必须区分上电复位、软件复位及应保留的数据，例如 IWDG 复位标志和 Flash 内容。

## 固件与外设

- BIN/HEX/ELF 共用范围校验；ELF 只装载有效 ARM `PT_LOAD` 段并保留可用符号。
- 每种外设保持独立头文件和实现文件；寄存器位、W1C、锁定、时钟门控和 IRQ 条件要有注释。
- 外设推进以 CPU 周期和选定时钟源计算，不因宿主运行速度或前端刷新频率改变固件时间。
- GPIO、串口、SPI、I2C、ADC、COMP 等宿主交互通过通用注入/回调接口完成，不读取示例全局变量。
- 只实现有资料和测试依据的行为；未实现高级模式应明确记录，不返回虚构成功结果。

## 验证

- 修改公共接口时同步更新所有调用方、Makefile 依赖、单元测试和文档。
- 性能优化前后比较指令结果、周期、异常和外设时间，不能只比较运行速度。
- 官方示例通过必须由固件可观察状态证明，例如发送数据、IRQ 回调、寄存器结果或内存内容。
