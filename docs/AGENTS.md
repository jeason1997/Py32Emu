# 文档规则

- 根 `README.md` 只保留能力概览、快速开始、常用命令、精度边界和文档导航。
- 详细架构、Web、指令覆盖、兼容矩阵、进度和已知限制分别放在 `docs/`。
- 命令必须与当前 Makefile/脚本一致，优先给出可复制的 WSL/Linux 示例。
- 新增型号、外设、CLI/Web 命令、官方示例或限制时同步更新对应文档。
- `PROGRESS.md` 记录历史事实但顶部必须反映当前口径；不要让旧阶段的 100% 被误读为整体兼容率。
- 完成审计必须区分“首个功能级版本”“官方示例全集兼容”和“逐周期完整仿真”。
- 兼容矩阵中的每个“通过”都应能追溯到测试脚本或实机记录；未经验证写“未验证”。
